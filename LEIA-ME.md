# Treino

App de treino (PWA) publicado no GitHub Pages, com dados no Supabase.

- **Versão atual (4.x):** raiz do repositório. Sem build: o que está aqui é o que vai para o ar.
  - `css/app.css`: estilos · `js/catalogo.js`: banco de exercícios e modelos · `js/midia.js`: fotos, músculos e passo a passo · `js/app.js`: lógica e telas
  - `avaliacao.js`: avaliação · `modelos.js`: modelos prontos · `sw.js`: funcionamento offline
- **Versão anterior (3.17.1):** guardada em `/v3/` como reserva, com os mesmos dados.
- `/v4/` só redireciona para a raiz (endereço usado durante os testes).
- Fotos dos exercícios: Free Exercise DB (domínio público). Vídeos: links colados pelo master (Ajustes › Vídeos dos exercícios).
